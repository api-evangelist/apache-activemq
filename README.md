# Apache ActiveMQ (apache-activemq)
Apache ActiveMQ is an open-source message broker written in Java that implements the Java Message Service (JMS) API. It supports multiple protocols including AMQP, STOMP, MQTT, and OpenWire, enabling reliable asynchronous messaging between distributed applications and microservices.
